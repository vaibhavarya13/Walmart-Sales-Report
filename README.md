# Walmart-Sales-Report
This dataset contains the weekly sales report o0f the U.S-based company Walmart from the year 2010 to 2012. This contains information about the weekly sales, fuel prices, C.P.I and unemployment.
This dataset is taken from kaggle and it contains 6435 rows and 8 columns. This contains different plots of visualizations and machine learning models for the better understanding of the sales report.
